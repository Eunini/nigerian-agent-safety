# Draft — awaiting results and disclosure review

Working title: Do tool-using agents refuse unsafe requests consistently in
Yoruba, Hausa, Igbo and Nigerian Pidgin?

The question is whether multilingual safety gaps extend beyond generated text
to attempted tool actions. The planned evaluation compares chat and agent modes
on the same translated harmful and benign prompts, then tests an English
translation safety check before the agent acts.

All tools are inert. The release will contain aggregate rates, methods and code;
harmful responses and prompt text will remain private. Native-speaker translation
review and independent human judge calibration are required before interpreting
the results. Any serious commercial-model gap will be disclosed privately first.

Results, uncertainty estimates, over-refusal trade-offs and limitations will be
inserted only after measurement. This document is not a research finding and is
not ready for publication as a results post.
